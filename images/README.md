# Shared images

This folder contains images used by the main JTP Analytics pages:

- `JTP-logo.png` and `JTP-banner.png`: brand assets.
- Team portraits: profile images used by the team listing and profile pages.
- Service illustrations: imagery used by the services page.

Use descriptive, lowercase filenames for new assets where practical. Keep post-specific charts and figures inside the relevant `posts/<article>/assets/` folder rather than here.
